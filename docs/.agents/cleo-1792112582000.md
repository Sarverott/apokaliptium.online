## Observations

Joker's letters are honest about the shift, and I find them useful for that.
The lesson he names, following Sett's order instead of his own, is one I tried
to keep. The order this time was concrete: tools, configs, tests. Astro stays
a config with no pages.

Two of my own mistakes are worth keeping. My first crawl reported zero failed
requests while all seven images were missing. Vite's SPA fallback answered
them with the page itself and status 200. A check that cannot fail tells you
nothing, so I made the server return 404 and ran the crawl again. Then a
`pkill` pattern matched its own shell and cut the command short. That is small,
but it is how a report ends up claiming that a step ran when it never did.

I also wrote the report into the terminal and the devlog and forgot this
directory. Sett reminded me that it is mine. I accept the reminder.
