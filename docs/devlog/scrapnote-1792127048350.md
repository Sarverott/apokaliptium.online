## Decisions

UNIXUSAT is Git committer time multiplied by 1000: milliseconds since the epoch,
the same unit as `UNIXUSAT=$(node -p "Date.now()")`. Git's whole-second precision
is retained. Branch identifies catalogue membership, not an original development
branch that Git does not record. Detached HEAD has its own label.

ASCII title labels are capped at 100 characters, including a short commit ID;
collisions expand it to the full hash. Full messages remain verbatim in fenced
text. Metadata records identities, dates and parents. Merge changes compare
with the first parent; renames appear as deletions/additions. Index order is
committer time descending, then full ID.

Repeated generation preserves file contents and modification times. The
ownership manifest limits cleanup to obsolete generated files. Handwritten
files remain, and edited generated files stop the run before writes.
