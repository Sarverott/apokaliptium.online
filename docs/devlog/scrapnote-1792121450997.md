## Tooling

  `app.js`; `task inspect` defaults to `http://localhost:4321/`.
- Tests run the dev server in a child process. Under Vitest (`VITEST=true`),
  Astro's dev server renders no client islands, which was isolated with a
  probe. The `astro dev` CLI cannot be used either: without a terminal, Astro

  outlives the test and blocks the next start through its lock. The test

  is another filesystem (EXDEV).
