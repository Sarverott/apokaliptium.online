## Publish failure

Run 38847336918 (PR #4 merge) failed in `npm test`. The dev-server suite
passed on the runner. The build suite failed with
`net::ERR_CONNECTION_REFUSED at http://127.0.0.1:36409/`. Cause:
`astro preview` binds to the name `localhost`. Locally that is 127.0.0.1;
on GitHub's Ubuntu runners `localhost` can resolve to ::1, so the server
listened on IPv6 while the test connected over IPv4. Ports are not
restricted there.

- Fix: both test servers bind to `127.0.0.1` explicitly.
- As Sett asked, the browser suite is wrapped in
  `describe.skipIf(GITHUB_ACTIONS === "true")`, with a NOTE saying how to
  re-enable it. The workflow no longer installs Chromium; its comment says
  what to add back. With `GITHUB_ACTIONS=true`, `npm test` skips 14 tests and
  exits 0.
