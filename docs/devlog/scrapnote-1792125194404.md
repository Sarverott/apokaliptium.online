## What failed before, run by run

- #4 (4a67a17): `astro preview` on `localhost` resolved to ::1 on the runner;
  ERR_CONNECTION_REFUSED. Fixed by binding tests to 127.0.0.1.
- #5, #6 (56f91dd, e2c20bb): the publish step's `git commit` ran the husky
  pre-commit hook. `npm ci` installs the hooks through `prepare`, and the
  runner had no `task` (`task: not found`, code 127). My earlier publish
  simulation missed this, because its clone never installed hooks. The
  `HUSKY=0` line Sett tried was a bare shell assignment, so `git` never saw it
  (not exported). Sett then added `@go-task/cli` (`a239bf6`), and the hook
  could run.
- The deploy steps: Pages now uses GitHub Actions as its source
  (`build_type: workflow`). In that mode `upload-pages-artifact` and
  `deploy-pages` are required. I removed them while Pages was in branch mode.
  Sett restored them in `bd5c8d3`. Sett was right; I should have asked before
  deleting steps Sett wrote.
