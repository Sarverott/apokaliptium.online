# Apokaliptium — Wspólna przyszłość

Filmowa, interaktywna prezentacja wizji cywilizacyjnej Apokaliptium, Inceptorium Apokryf, RedScope Technologies i Radio Kocia Muzyka.

Przepisana z pierwotnego statycznego projektu na nowoczesną aplikację **React 19 + TypeScript + Vite**.

## Główne moduły i funkcjonalności

- **01 / Wspólny horyzont** — Wprowadzenie, wizja otwartej platformy dla wspólnej przyszłości z animowanym tłem orbitalnym i blaskiem.
- **02 / Inceptorium Apokryf** — Warsztat badawczy, otwarta nauka, prototypowanie i dokumentacja.
- **03 / Sieć możliwości** — Zdecentralizowana infrastruktura, węzły współpracy i zasady: otwarte protokoły, ciągłość wiedzy, logistyka.
- **04 / RedScope Technologies** — Inżynieria przemysłowa, produkcja i komercjalizacja innowacji.
- **05 / Radio Kocia Muzyka** — Głos społeczności, kultura i edukacja z dynamicznym korektorem audio (48 zsynchronizowanych słupków falowych).
- **06 / Różne umysły** — Ludzie × Sztuczne inteligencje: chór perspektyw (Ace, Artur, Spektor, Varo, Sett Sarverott).
- **07 / Droga do typu III** — Horyzontalna oś czasu z 6 klatkami wizji przyszłości oraz odnośnik do archiwum UCDI.

## Interakcja i sterowanie

- **Pasek postępu (Rail)** — Pionowy wskaźnik głębokości przewijania oraz automatyczny licznik aktualnej klatki (`01 / 07` – `07 / 07`).
- **Przełącznik ruchu (Motion Toggle)** — Możliwość wstrzymania i wznowienia animacji kinowych (wsparcie dla `prefers-reduced-motion`).
- **Nawigacja rozdziałów (Chapters Menu)** — Dostępna klawiaturowo szuflada rozdziałów z obsługą klawisza Escape i płynnym przewijaniem.

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Aplikacja uruchamia się pod adresem `http://localhost:3000`.
